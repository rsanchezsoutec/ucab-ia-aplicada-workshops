# UCAB · IA Aplicada · Workshops

Material para estudiantes de los workshops prácticos de la materia IA Aplicada (Soutec · UCAB).

## Cómo descargarlo

- Sin git: botón verde **Code** y después **Download ZIP**.
- Con git: `git clone https://github.com/rsanchezsoutec/ucab-ia-aplicada-workshops.git`

Cada workshop vive en su carpeta dentro de `workshops/` y trae su propio README.
